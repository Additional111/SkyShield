# SkyShield

SkyShield este un MVP pentru detectarea anomaliilor în comunicațiile aeroportuare.

## Obiectiv
Detectăm mesaje ADS-B/ACARS suspecte, calculăm un scor de risc și afișăm alerte pe un dashboard în timp real.

## Tehnologii
- C# / .NET
- ASP.NET Core Web API
- SignalR
- HTML + JavaScript + Leaflet.js

## MVP
1. Simulare de trafic aerian.
2. Reguli simple de detecție a anomaliilor.
3. Scor de risc 0-100.
4. Dashboard cu hartă și alerte.
5. Buton de simulare a unui atac.
